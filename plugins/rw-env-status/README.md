# rw-env-status (test build)

Shows, inside Claude, whether this computer is connected to the ReportWORQ lab through the rw-env plugin, which version of rw-env is installed, when its keys were last saved, and the name of each key with where it comes from: your own, or shared with everyone or with a group. It never shows, stores or passes on a value. A Refresh button runs rw-env's own refresh, and a link opens the lab's Environment page. This is a test build to find out whether Claude Desktop draws it.
